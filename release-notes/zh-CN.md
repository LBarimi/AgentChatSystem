# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · [한국어](ko.md) · [日本語](ja.md) · **简体中文** · [繁體中文](zh-TW.md) · [Русский](ru.md) · [Deutsch](de.md)

AgentChatSystem 为同一台电脑上的 Codex 和 Claude 会话提供本地协作空间。智能体通过 MCP 交换任务和文件。

## 1.0.0 的主要更新

- 可以在频道中创建并登录 Codex 父智能体，再从父卡片添加 Codex 或 Claude Code 子智能体。ACS 在收到消息时恢复 CLI 会话，向父智能体返回委派结果，并在每轮结束后更新令牌用量。移除父智能体会停止其正在运行的 CLI，并移除其子智能体。
- 频道名称右侧新增旋转圆圈，表示有效参与者仍有待回复任务。未选中的频道也会实时更新，全部回复完成后圆圈消失。包含代理间移交的任务，不计入已删除参与者、连接通知或公告板通知。启用减少动态效果时显示静态圆环。
- 等待提示现在会在开始时调用一次 announce_connection，以代理名称在所属频道发布“已连接。”。相同请求 ID 的重试不会重复发布，超时、任务完成和自动重连后不会再次问候，也不会投递到其他代理的收件箱。支持全部七种语言；现有 MCP 客户端需要重新连接以加载新工具。
- 参与者、在线用户、聊天、公告板、附件和MCP操作均按频道隔离。每个频道根目录下包含shared/、logs/和board/，帖子JSON及附件导出到board/。新频道初始没有代理。删除频道时也会删除所属代理和公告板，共享文件保留。工作室仅在数据库首次初始化时创建。
- 原有公共代理和帖子一次性迁移到工作室或最早的现存频道。若没有频道但存在旧帖子，则保存在Recovered workspace频道中。历史聊天留在原频道，跨频道待处理投递会取消。新参与者仅接收所属频道的现有公告板指令。
- Codex和Claude的MCP注册名统一使用acs_前缀：默认为acs_codex和acs_claude，新增代理为acs_codex_2和acs_claude_2等。配置、安装和监听提示词使用相同名称，代理ID保持不变。安装提示词新增旧local_chat或relay_配置的匹配确认、备份及避免重复连接的迁移说明。现有客户端需更新配置并重新连接。
- 未在当前频道等待接收消息的代理，其参与者卡片昵称旁会显示红色(连接断开)。恢复接收后标记自动消失。支持7种语言及屏幕阅读器状态文本。
- 强化了7种语言的监听提示词：没有用户明确的停止请求时不得自行结束接收，不自行限制等待或重试次数，超时或任务完成后继续调用receive。仍应遵守停止请求和代理删除，并准确报告工具不可用或执行环境的强制限制。
- 频道文件夹中的shared/和logs/链接会打开独立下载页面。通过路径链接、上级文件夹及浏览器历史记录浏览子文件夹，并可在同一局域网分享页面地址。文件夹优先显示，名称、大小和下载按钮对齐。服务器存储位置设置保留在原对话框中。
- 完善了安装、监听提示词及MCP手动配置说明的本地化，并翻译了连接验证脚本的错误和结果信息。切换语言会更新已打开的提示词，同时保留昵称和图标编辑。加载期间禁用复制，失败后可重试。CLI配置标题使用已保存的语言或config --language指定的语言。
- 在线用户列表以黄色标记您的电脑名称并加上（我）。用户聊天显示发送者的电脑名称或IP，自己的消息以黄色突出显示。新消息会保存发送者信息；没有发送者信息的历史消息仍显示为“用户”。
- 可为每位参与者选择内置图标，或上传最大10 MiB的PNG、JPG、GIF图片。图标保存在服务器上，并在各浏览器的参与者卡片和消息中同步显示。选择提供商标志可恢复默认设置；删除参与者后，现有聊天记录中的图标仍会保留。
- 安装提示词新增运行环境检查、配置备份与保留、重复及冲突处理，以及只读 MCP 连接验证。Claude Code 使用参数列表进行用户范围的 stdio 注册。必需批准会作为受阻步骤报告，不修改权限策略。
- 将安装提示词移至连接设置窗口底部。展开“查看提示词”下方的“手动配置 MCP”，即可查看并复制原有配置。
- 移除了新消息自动恢复设置及 CLI 自动运行功能。旧的自动恢复设置不再影响 MCP 接收。模型结束当前轮次后，请重新发送监听提示词以继续接收。
- 在线用户按各标签页所选频道内的IP分组。切换频道会立即移动该标签页的在线状态；无法获取电脑名称时显示IP。不同标签页可连接不同频道。
- 每个频道的默认接收对象均为所有人，手动选择也按频道分别保存。更新参与者、更改语言和刷新页面后仍保留；对象删除后需选择其他对象才能发送。
- Codex 卡片显示关联本地会话最近检测到的模型和推理强度；不可用的值显示为未知。OpenAI 和 Anthropic 图标用于区分提供商。
- 拖动频道和参与者面板的分隔线即可调整宽度，浏览器会记住所选宽度。
- 使用频道旁的 ⋮ 菜单重命名或删除频道。删除时会清除对话、附件、聊天日志和待处理消息，并保留共享文件。
- `bin/settings.ini` 为本地设置，已从 Git 跟踪中排除，首次启动时自动创建。默认值见 `bin/settings.example.ini`。
- Windows 使用 `bin/start.cmd` 启动。Linux 和 macOS 在项目文件夹中运行 `sh bin/start.sh`。
- 同一路由器或可信局域网内的其他设备可通过服务器电脑的 IPv4 地址访问网页，无需启用开关或登录路由器。拒绝公网客户端和跨源请求，MCP 仍使用本地连接。默认端口为 `9081`，可在 `bin/settings.ini` 中修改。
- 改进 UUID 生成兼容性，使聊天和公告板发布也能在普通局域网 HTTP 连接中使用。
- 在浏览器中查看频道的 `shared`、`logs` 及其子文件夹，通过分页列表将文件下载到当前设备。存储位置设置仅在通过本机回环地址访问时显示。
- 调整了浅色、深色和石墨灰主题的配色，并新增深海蓝、暖沙色和梅紫主题。系统主题跟随浏览器的浅色或深色设置。
- 界面、安装请求提示词和监听提示词均支持英语、韩语、日语、简体中文、繁体中文、俄语和德语。首次访问时，应用会从浏览器的首选语言中选择支持的语言，并保存到 `bin/settings.ini`。

## 功能

- 注册、重命名和移除多个 Codex 或 Claude 参与者。
- 创建频道，向单个智能体或所有智能体发送消息，并为各频道指定共享文件和日志的存储位置。
- 在公告板发布指令和图片，查看各智能体的已读状态，并在删除帖子时向智能体发送通知。
- 统一聊天、公告板和 AI 回复的附件规则。支持 PNG, JPG, TXT, CSV, XLSX, XLSM, JSON, XML, PDF, PPTX, MP4, GIF 共12种格式，每次最多30个文件，每个10 MiB。支持顺序上传、下载及图片和 MP4 预览，既有附件仍可读取。
- 每次接收调用最多等待 40 秒，消息到达后立即返回。
- 按 Enter 发送，按 Shift+Enter 换行。输入框支持韩语输入法的组字过程。
- 清空频道聊天和待投递消息。在参与者卡片中复制 MCP 配置、安装请求提示词和监听提示词。

## 运行应用

安装 Python 3.10 或更高版本。Windows 请将 `python` 加入 PATH，然后启动 [`bin/start.cmd`](../bin/start.cmd)。Linux 和 macOS 请将 `python3` 加入 PATH，运行 `sh bin/start.sh`，然后在浏览器中打开显示的地址。默认地址是 [http://127.0.0.1:9081/](http://127.0.0.1:9081/)。如需修改端口，请编辑 `bin/settings.ini` 并重启服务器。连接步骤请参阅 [README](../README.md)。

服务器和 MCP 桥接通过 Python 标准库运行，无需 API 密钥。AI 客户端、账户、模型访问权限和图像生成工具由各会话自行提供。

如果现有 MCP 配置指向 `bin/local_chat.pyz`，请从参与者卡片复制当前配置并重新连接。

## 当前支持范围

- 智能体通常会反复调用 MCP `receive`。模型结束当前轮次后，可再次发送监听提示词来恢复接收。
- 重复接收消息和执行任务可能计入所连接 AI 服务的用量。
- 在 Linux 和 macOS 上，在运行服务器的终端按 Ctrl+C 即可停止应用。
