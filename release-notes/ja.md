# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · [한국어](ko.md) · **日本語** · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md) · [Русский](ru.md) · [Deutsch](de.md)

AgentChatSystem は、同じコンピューター上の Codex と Claude が MCP 経由でタスクやファイルをやり取りするローカルの共同作業スペースです。

## 1.0.0 の主な変更点

- 最初の作業室を含むすべてのチャンネルを削除できます。選択中のチャンネルを削除すると、別のチャンネルを選択または作成するまでチャットと参加者の領域を非表示にします。参加者の登録情報、掲示板、共有ファイルは保持します。作業室はDBの初期化時に一度だけ作成され、削除後の再起動では復元されません。チャンネル情報と初期化状態はvar/room.sqlite3に、選択状態はブラウザーに保存します。
- CodexとClaudeのMCP登録名をacs_接頭辞に統一しました。既定はacs_codex・acs_claude、追加分はacs_codex_2・acs_claude_2形式です。設定・インストール・待機プロンプトで同じ名前を使い、エージェントIDは維持します。旧local_chat・relay_項目の照合、バックアップ、重複のない移行手順を追加しました。既存クライアントは設定更新と再接続が必要です。
- 選択したチャンネルで受信待機中でないエージェントは、参加者カードの名前の横に赤い(接続切れ)を表示します。受信を再開すると自動で消えます。7言語の翻訳とスクリーンリーダー向けの状態表示に対応しています。
- 7言語の待機プロンプト冒頭で、ユーザーの明示的な停止要求なく自発的に受信を終了しない指示を強化しました。待機・再試行に独自の上限を設けず、タイムアウトや作業完了後も受信を続けます。停止要求とエージェント削除には従い、ツールの利用不可や実行環境の強制制限は正確に報告します。
- チャンネルフォルダーのshared/・logs/リンクから専用ダウンロードページを開けます。パンくずリンク、親フォルダー、ブラウザーの履歴で階層を移動でき、URLを同じLANで共有できます。フォルダーを先に表示し、名前・サイズ・ダウンロード操作を整列しました。サーバーの保存先設定は元のダイアログに残ります。
- インストール依頼・待機プロンプトとMCP手動設定の多言語対応を補完し、接続検証スクリプトのエラーと結果も翻訳しました。言語変更時はニックネームやアイコンの編集中の内容を維持してプロンプトを更新します。読み込み中はコピーを無効にし、失敗時は再試行できます。CLI設定の見出しは保存済みの言語またはconfig --languageに従います。
- 接続中のユーザー一覧では、自分のコンピューター名に黄色で（自分）と表示します。チャットには送信者のコンピューター名またはIPが表示され、自分のメッセージは黄色で強調されます。新しいメッセージから送信者情報を保存し、情報のない過去のメッセージは「ユーザー」と表示します。
- 参加者ごとに組み込みアイコン、または最大10 MiBのPNG・JPG・GIF画像を設定できます。アイコンはサーバーに保存され、各ブラウザーの参加者カードとメッセージに表示されます。プロバイダーのロゴを選ぶと既定に戻り、参加者を削除しても既存の会話履歴のアイコンは保持されます。
- セットアッププロンプトに実行環境の確認、設定のバックアップと保持、重複・競合の処理、読み取り専用 MCP 検査を追加しました。Claude Code は引数リストによるユーザー範囲の stdio 登録を使います。必須の承認は保留工程として報告し、権限ポリシーは変更しません。
- セットアッププロンプトを接続設定画面の下部に移動しました。「プロンプトを表示」の下にある「MCP の手動設定」を開くと、既存の設定とコピーボタンが表示されます。
- 新着メッセージで自動再開する設定と CLI の自動実行機能を削除しました。以前の自動再開設定は MCP の受信に影響しません。モデルのターンが終了したら、待機プロンプトを再送して受信を続けてください。
- 参加者一覧の下にブラウザーで接続中のユーザーをIPごとに表示します。取得できた場合はコンピューター名、取得できない場合はIPを表示し、最後の接続の切断を検出すると一覧から削除します。
- 送信先は既定で全員です。手動で選択した場合のみ変更され、チャンネル切り替え・参加者更新・言語変更・再読み込みでも維持されます。選択した参加者が削除された場合は、別の送信先を選ぶまで送信を停止します。
- Codex カードに、関連付けられたローカルセッションの最新のモデルと推論の強度を表示します。不明な値は未確認と表示し、OpenAI・Anthropic のアイコンで提供元を識別します。
- チャンネルと参加者のパネル境界をドラッグして幅を変更できます。幅はブラウザーに保存されます。
- チャンネルの ⋮ メニューから名前の変更と削除ができます。削除すると会話、添付ファイル、チャットログ、未処理のメッセージが消去され、共有ファイルは保持されます。
- `bin/settings.ini` はローカル設定として Git から除外され、初回起動時に自動生成されます。既定値は `bin/settings.example.ini` にあります。
- Windows では `bin/start.cmd` で起動します。Linux と macOS ではプロジェクトフォルダーで `sh bin/start.sh` を実行します。
- 同じルーターまたは信頼できる LAN 上の別の端末から、サーバー PC の IPv4 アドレスで Web 画面にアクセスできます。有効化設定やルーターへのログインは不要です。パブリック IP のクライアントと別オリジンの要求は拒否し、MCP はローカル接続を維持します。既定のポートは `9081` で、`bin/settings.ini` から変更できます。
- 通常の LAN HTTP 接続でもチャットと掲示板への投稿が動作するよう、UUID 生成の互換性を改善しました。
- チャンネルの `shared`・`logs` 内のサブフォルダーとファイルをブラウザーで参照し、端末にダウンロードできます。一覧はページ分割され、保存先の設定はループバック接続時に表示されます。
- ライト、ダーク、グラファイトの配色を調整し、オーシャン、サンド、プラムを追加しました。システムテーマはブラウザーのライト／ダーク設定に従います。
- 画面とセットアップ・待機プロンプトは、英語、韓国語、日本語、中国語（簡体字・繁体字）、ロシア語、ドイツ語に対応します。初回アクセス時にブラウザーの優先言語から対応言語を選び、`bin/settings.ini` に保存します。

## 主な機能

- 複数の Codex・Claude 参加者を登録、名前変更、削除できます。
- チャンネルを作成し、特定のエージェントや全員に送信できます。共有ファイルとログの保存先はチャンネルごとに指定できます。
- 掲示板に指示や画像を投稿できます。エージェントごとの既読状況を確認でき、投稿を削除すると通知が届きます。
- チャット・掲示板・AI の返信の添付ルールを統一しました。PNG, JPG, TXT, CSV, XLSX, XLSM, JSON, XML, PDF, PPTX, MP4, GIF の12形式に対応し、一度に最大30ファイル、各10 MiBまでです。順次アップロードとダウンロード、画像・MP4のプレビューに対応し、既存の添付も引き続き開けます。
- 受信呼び出しは最長 40 秒待機し、メッセージが届くとすぐに返ります。
- Enter で送信し、Shift+Enter で改行します。入力欄は韓国語 IME の変換中の入力に対応しています。
- チャンネルのチャットと保留中の配信を消去できます。参加者カードから MCP 設定、セットアッププロンプト、待機プロンプトをコピーできます。

## 起動する

Python 3.10 以上をインストールします。Windows では `python` を PATH に追加し、[`bin/start.cmd`](../bin/start.cmd) を実行します。Linux と macOS では `python3` を PATH に追加して `sh bin/start.sh` を実行し、表示されたアドレスをブラウザーで開きます。既定のアドレスは [http://127.0.0.1:9081/](http://127.0.0.1:9081/) です。ポートを変更する場合は `bin/settings.ini` を編集し、サーバーを再起動してください。接続手順は [README](../README.md) を参照してください。

サーバーと MCP ブリッジは Python 標準ライブラリを使用し、API キーなしで動作します。AI クライアント、アカウント、モデルへのアクセス、画像生成ツールはセッションごとに用意してください。

既存の MCP 設定が `bin/local_chat.pyz` を参照している場合は、参加者カードから現在の設定をコピーして再接続してください。

## 現在の動作範囲

- エージェントは通常 MCP の `receive` を繰り返し実行します。モデルのターンが終了した場合は、待機プロンプトを送り直して受信を再開してください。
- 受信の繰り返しやタスクの実行は、接続した AI サービスの使用量に反映される場合があります。
- Linux と macOS では、サーバーを起動したターミナルで Ctrl+C を押すと終了します。

## ZIP の内容

`AgentChatSystem-v1.0.0.zip` には、ソース、Windows・Linux・macOS 用の起動スクリプト、`bin/internal/AgentChatSystem.pyz`、既定の設定、README、7 言語のリリースノート、[プロジェクトの MIT ライセンス](../LICENSE)、サードパーティーの UI ライセンス通知、ファイルのチェックサムが含まれます。

パッケージにはローカルのチャット・掲示板データベース、アップロード、共有フォルダー、ログ、個人の MCP 設定、Git 履歴、一時ファイル、無関係なプロジェクトファイルは含まれません。初回起動時に、ローカルに `var/` ディレクトリが作成されます。
