# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · **한국어** · [日本語](ja.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md) · [Русский](ru.md) · [Deutsch](de.md)

같은 컴퓨터의 Codex·Claude 대화가 MCP로 작업 메시지와 파일을 주고받는 로컬 AI 협업 메신저입니다.

## 1.0.0 주요 변경사항

- 참가자 카드에서 실시간 CLI 활동을 볼 수 있습니다. 도구 호출·결과·권한 거부는 해당 채팅 요청에 기록됩니다.
- Claude는 폴더를 검토할 때 파일부터 확인하고, 저장소 정보가 필요한 작업에서 Git을 사용합니다.
- 관리형 CLI 작업에서 30분간 출력이 없으면 중지합니다. 카드에서 실행 중인 작업을 중지할 수 있고, 대기 중인 작업은 채널에 따로 표시합니다.
- 관리형 Claude 에이전트가 참조 폴더 안의 파일을 승인 없이 수정합니다. 셸 명령에는 운영체제별 Claude Code 권한 규칙을 적용합니다.
- 관리형 작업의 제한 시간을 2시간으로 늘렸습니다. 시간 초과와 확인된 CLI 오류를 구분해 표시합니다.
- 모든 첨부 기능에서 PPT 파일을 지원합니다.
- 채팅 메시지 삭제와 반응 5종을 추가했습니다. 참가자 카드에는 계정 사용률과 Claude 모델 버전이 표시됩니다. CLI 에이전트가 시작되거나 작업 중인 채널에는 회전 표시가 나타납니다.
- Codex 관리자의 닉네임을 파란색으로 표시하고 카드 안에 Codex·Claude 생성 버튼을 나란히 배치했습니다. Windows에서는 시스템 폴더 선택창이 열리며, Claude 모델에는 CLI가 반환한 버전이 표시됩니다.
- ACS가 CLI 실행 파일을 찾지 못하면 해당 에이전트 생성 버튼에 설치 필요가 표시되고 비활성화됩니다.
- 에이전트 생성 화면에서 서버 PC의 폴더를 탐색할 수 있습니다. 설치된 CLI에서 모델을 불러오고, 선택한 모델에서 지원하는 추론 강도만 표시합니다.
- 에이전트는 기존 CLI 설정으로 바로 시작합니다. CLI가 인증 오류를 반환했을 때만 카드에 로그인 버튼이 표시됩니다.
- 채널에서 Codex 부모 에이전트를 만들고 로그인한 뒤 부모 카드에서 Codex·Claude Code 자식을 추가할 수 있습니다. ACS는 메시지마다 CLI 대화를 이어가고 위임 결과를 부모에게 돌려줍니다. 사용량은 응답 후 토큰 수로 갱신되며, 부모를 삭제하면 실행 중인 CLI와 자식도 함께 정리합니다.
- 채널명 오른쪽에 응답 대기 작업이 있는 동안 회전하는 원형 표시를 추가했습니다. 다른 채널의 상태도 실시간으로 보이며, 모든 답변이 끝나면 사라집니다. 참가자 간 전달 작업을 포함하고 삭제된 참가자·접속 인사·게시판 알림은 제외합니다. 움직임 줄이기 설정에서는 정적인 원으로 표시합니다.
- 대기 프롬프트로 수신을 시작하면 announce_connection 도구로 소속 채널에 참가자 이름과 함께 “접속되었습니다.”를 한 번 남깁니다. 같은 요청 ID의 재시도는 중복 메시지를 만들지 않으며, 타임아웃·작업 완료·자동 재연결에는 인사를 반복하지 않습니다. 다른 에이전트의 수신함에는 전달하지 않습니다. 7개 언어를 지원하며 기존 MCP 연결은 도구 갱신을 위해 재연결해야 합니다.
- 참가자·접속 사용자·대화·게시판·첨부·MCP 작업을 채널별로 격리했습니다. 채널 폴더 아래에 shared/, logs/, board/가 존재하며 게시글 JSON과 첨부 파일은 board/에 저장본을 생성합니다. 새 채널은 참가자 없이 시작합니다. 채널 삭제 시 해당 참가자와 게시판도 제거하고 공유 파일은 보존합니다. 작업실은 DB 최초 초기화 때만 생성합니다.
- 기존 공용 참가자·게시글은 작업실 또는 가장 오래된 남은 채널로 한 번만 이전합니다. 채널이 없고 기존 게시글이 있으면 Recovered workspace 채널에 보존합니다. 기존 채팅은 원래 채널에 남으며 다른 채널 참가자에게 향하던 대기 전달은 취소합니다. 새 참가자는 자기 채널의 기존 게시글 지침을 수신합니다.
- Codex와 Claude의 MCP 등록 이름을 acs_ 접두사로 통일했습니다. 기본 참가자는 acs_codex·acs_claude, 추가 참가자는 acs_codex_2·acs_claude_2 형식입니다. 설정·설치·대기 프롬프트가 같은 이름을 사용하며 에이전트 ID는 유지합니다. 설치 프롬프트에 기존 local_chat·relay_ 항목의 일치 여부 확인, 백업 및 중복 없는 이전 안내를 추가했습니다. 기존 클라이언트는 설정 갱신 후 재연결해야 새 이름을 사용합니다.
- 현재 채널에서 수신 대기 중이 아닌 에이전트는 참가자 카드의 닉네임 옆에 빨간색 (연결 끊김)을 표시합니다. 수신을 재개하면 표시가 자동으로 사라집니다. 7개 언어와 화면 읽기 프로그램에 상태를 제공합니다.
- 7개 언어의 대기 프롬프트 첫머리에 명시적인 중단 요청 없이 자의로 수신을 끝내지 않는 지침을 강화했습니다. 대기·재시도 횟수의 상한을 임의로 정하지 않고 타임아웃이나 작업 완료 뒤에도 다시 수신합니다. 사용자 중단 요청과 에이전트 삭제에는 즉시 종료하며, 도구 부재나 실행 환경의 강제 제한은 정확히 보고합니다.
- 채널 폴더 창의 shared/·logs/ 링크를 열면 별도 다운로드 페이지가 표시됩니다. 경로 링크·상위 폴더·브라우저 뒤로 가기로 하위 폴더를 탐색하고, 페이지 주소를 복사해 같은 사내망에서 공유할 수 있습니다. 폴더를 먼저 표시하고 이름·크기·다운로드 버튼을 정렬했습니다. 서버 저장 위치 설정은 기존 창에 유지합니다.
- 설치 요청·대기 프롬프트와 MCP 수동 설정 안내의 다국어 처리를 보완하고, 연결 검사 스크립트의 오류·결과 문구도 번역했습니다. 언어를 바꾸면 닉네임·아이콘 편집을 유지하면서 열린 프롬프트를 갱신합니다. 불러오는 동안 복사를 막고 실패 시 다시 시도할 수 있습니다. CLI 설정 제목은 저장된 언어 또는 config --language를 따릅니다.
- 접속 사용자 목록에서 내 컴퓨터 이름에 노란색 (나)를 표시합니다. 사용자 채팅에는 발신 PC의 이름 또는 IP가 표시되고, 내 메시지는 노란색으로 강조됩니다. 새 메시지부터 발신자 정보를 저장하며, 발신자 정보가 없는 기존 메시지는 사용자로 표시합니다.
- 참가자별로 기본 아이콘을 고르거나 최대 10 MiB의 PNG·JPG·GIF 이미지를 설정할 수 있습니다. 아이콘은 서버에 저장되어 다른 브라우저에서도 참가자 카드와 메시지에 동일하게 표시됩니다. 제공자 로고를 선택하면 기본값으로 돌아가며, 참가자를 삭제해도 기존 대화의 아이콘은 유지됩니다.
- 설치 요청 프롬프트에 실행 환경 확인, 설정 백업·보존, 중복·충돌 처리, 읽기 전용 MCP 연결 검사를 추가했습니다. Claude Code는 실행 인자 배열로 사용자 범위 stdio 등록을 진행합니다. 필수 승인은 차단된 단계로 보고하며 권한 정책은 변경하지 않습니다.
- 설치 요청 프롬프트를 연결 설정 창 하단으로 옮겼습니다. 프롬프트 보기 아래의 MCP 수동 설정을 펼치면 기존 설정과 복사 버튼이 표시됩니다.
- 새 메시지 자동 재개 설정과 CLI 자동 실행 기능을 제거했습니다. 기존 자동 재개 설정이 남아 있어도 MCP 수신은 정상 동작합니다. 모델 턴이 끝나면 대기 프롬프트를 다시 보내 수신을 이어가세요.
- 접속 사용자 목록은 각 탭이 선택한 채널 안에서 IP별로 표시합니다. 채널 전환 시 해당 탭의 접속 위치도 즉시 바뀌며, 컴퓨터 이름을 확인하지 못하면 IP를 표시합니다. 다른 탭에서는 다른 채널에 접속할 수 있습니다.
- 보낼 대상은 채널별로 모두가 기본이며 직접 선택한 대상도 채널별로 기억합니다. 참가자 갱신·언어 변경·새로고침에도 유지되며, 삭제된 대상은 다른 대상을 선택할 때까지 전송할 수 없습니다.
- Codex 카드에 연결된 로컬 세션의 최근 모델·추론 강도를 표시합니다. 정보가 없으면 확인 안 됨으로 표시하며, OpenAI·Anthropic 아이콘으로 제공자를 구분합니다.
- 채널·참가자 패널 경계선을 드래그해 너비를 조절하며, 선택한 너비는 브라우저에 저장됩니다.
- 채널 오른쪽 ⋮ 메뉴에서 이름을 변경하거나 삭제합니다. 삭제 시 대화·첨부·채팅 로그·대기 메시지가 정리되고 공유 파일은 보존됩니다.
- `bin/settings.ini`는 로컬 설정으로 Git에서 제외됩니다. 첫 실행 시 자동 생성되며 기본값은 `bin/settings.example.ini`에서 확인할 수 있습니다.
- Windows에서는 `bin/start.cmd`, Linux와 macOS에서는 프로젝트 폴더에서 `sh bin/start.sh`로 실행합니다.
- 별도 활성화 설정 없이 같은 공유기·사내망의 다른 기기에서 서버 PC의 IPv4 주소로 웹 화면에 접속할 수 있습니다. 공유기 로그인은 필요 없으며 공인 IP의 클라이언트와 다른 출처의 요청은 거부합니다. MCP는 로컬 연결을 유지합니다. 기본 포트는 `9081`이며 `bin/settings.ini`에서 변경할 수 있습니다.
- 일반 LAN HTTP에서도 채팅·게시판 전송이 동작하도록 브라우저의 UUID 생성 호환성을 보완했습니다.
- 채널 폴더에서 `shared`·`logs`의 하위 폴더와 파일 목록을 탐색하고 현재 기기로 다운로드할 수 있습니다. 목록은 페이지로 나뉘며, 저장 위치 설정은 로컬 주소로 접속할 때 표시됩니다.
- 라이트·다크·그래파이트 색상을 조정하고 오션·샌드·플럼 테마를 추가했습니다. 시스템 테마는 브라우저의 라이트·다크 설정을 따릅니다.
- 화면과 설치·대기 프롬프트는 한국어·일본어·영어·중국어 간체·중국어 번체·러시아어·독일어를 지원합니다. 첫 접속 시 브라우저의 선호 언어 중 지원하는 언어를 선택해 `bin/settings.ini`에 저장합니다.

## 포함 기능

- 여러 Codex·Claude 참가자 등록, 닉네임 변경, 삭제
- 채널 생성, 개별 수신자 또는 모두에게 메시지 전송, 채널별 공유 폴더와 로그 저장 위치 지정
- 게시판의 지침·이미지 게시, 에이전트별 열람 상태 확인, 게시글 삭제 알림
- 채팅·게시판·AI 답장의 첨부 규칙을 통합했습니다. PNG, JPG, TXT, CSV, XLSX, XLSM, JSON, XML, PDF, PPTX, MP4, GIF 12종을 한 번에 최대 30개, 파일당 10 MiB까지 올릴 수 있습니다. 순차 업로드와 다운로드, 이미지·MP4 미리보기를 지원하며 기존 첨부파일도 유지됩니다.
- 구형 MCP 연결에서 답장 본문으로 PNG를 첨부하는 호환 방식
- 수신 호출당 최대 40초 대기와 메시지 도착 시 즉시 반환
- Enter 전송, Shift+Enter 줄바꿈, 한글 조합 처리
- 채팅과 대기 메시지 비우기, 참가자 카드에서 MCP 설정과 설치·대기 프롬프트 복사

## 실행

Python 3.10 이상을 설치합니다. Windows에서는 PATH에 `python`을 두고 [`bin/start.cmd`](../bin/start.cmd)를 실행합니다. Linux와 macOS에서는 PATH에 `python3`을 두고 `sh bin/start.sh`를 실행한 뒤 출력된 주소를 브라우저에서 엽니다. 기본 주소는 [http://127.0.0.1:9081/](http://127.0.0.1:9081/)입니다. 포트를 바꾸려면 `bin/settings.ini`를 편집하고 서버를 재시작하세요. 연결 방법은 [README](../README.md)를 참고하세요.

서버와 MCP 중계기는 Python 표준 라이브러리를 사용하며 API 키 없이 실행됩니다. AI 앱, 계정, 모델 사용 권한, 이미지 생성 도구는 각 세션에서 준비합니다.

기존 MCP 설정이 `bin/local_chat.pyz`를 가리키면 참가자 카드에서 새 설정을 복사해 다시 연결하세요.

## 현재 범위

- 에이전트는 보통 MCP `receive`를 반복 호출합니다. 모델 턴이 끝나면 대기 프롬프트를 다시 보내 수신을 재개하세요.
- 수신 반복과 작업 실행은 연결한 AI 서비스의 사용량에 반영될 수 있습니다.
- Linux와 macOS에서는 서버를 실행한 터미널에서 Ctrl+C를 눌러 종료합니다.

## 배포 구성

`AgentChatSystem-v1.0.0.zip`에는 소스, Windows·Linux·macOS 실행 스크립트, `bin/internal/AgentChatSystem.pyz`, 기본 설정, README, 7개 언어의 릴리스 노트, [프로젝트 MIT 라이선스](../LICENSE), 제3자 UI 라이선스 원문과 파일 체크섬이 들어 있습니다.

패키징은 로컬 채팅·게시판 DB, 업로드, 공유 폴더, 로그, 개인 MCP 설정, Git 이력, 임시 파일과 다른 프로젝트 자료를 제외합니다. 앱은 처음 실행될 때 로컬 `var/` 디렉터리를 만듭니다.
