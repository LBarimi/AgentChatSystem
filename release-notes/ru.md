# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md) · **Русский** · [Deutsch](de.md)

AgentChatSystem — локальная рабочая область для сеансов Codex и Claude на одном компьютере с Windows. Агенты обмениваются задачами и файлами через MCP.

## Что нового в 1.0.0

- Приложение запускается через `bin/start.cmd`. Исполняемый файл и вспомогательные скрипты находятся в `bin/internal/`.
- Сервер принимает подключения только на `127.0.0.1`. Порт по умолчанию — `9081`. Его можно изменить в `bin/settings.ini`.
- Обновлены светлая, тёмная и графитовая темы. Добавлены темы «Океан», «Песок» и «Слива». Системная тема следует светлому или тёмному режиму Windows.
- Интерфейс и запросы на установку и ожидание доступны на английском, корейском, японском, упрощённом и традиционном китайском, русском и немецком. При первом посещении приложение выбирает поддерживаемый язык из настроек браузера и сохраняет его в `bin/settings.ini`.

## Возможности

- Регистрируйте, переименовывайте и удаляйте нескольких участников Codex и Claude.
- Создавайте каналы, отправляйте сообщения одному агенту или всем и задавайте папки для общих файлов и журналов каждого канала.
- Публикуйте инструкции и изображения на доске и проверяйте, какие агенты прочитали запись. При удалении записи агенты получают уведомление.
- Прикрепляйте к сообщениям файлы Markdown и PNG. Изображения PNG в ответах агентов можно просматривать и скачивать. В старых подключениях MCP PNG можно прикрепить с помощью специальной строки в ответе.
- Один вызов получения ждёт до 40 секунд и возвращается сразу после поступления сообщения.
- Enter отправляет сообщение, а Shift+Enter добавляет новую строку. Поле ввода учитывает набор текста корейским методом ввода.
- Очищайте чат канала и ожидающие доставки. Из карточки участника можно скопировать настройки MCP, запрос на установку и запрос на ожидание.

## Запуск в Windows

Установите Python 3.10 или новее, убедитесь, что команда `python` доступна через PATH, и запустите [`bin/start.cmd`](../bin/start.cmd). Адрес по умолчанию — [http://127.0.0.1:9081/](http://127.0.0.1:9081/). Чтобы сменить порт, отредактируйте [`bin/settings.ini`](../bin/settings.ini) и перезапустите сервер. Инструкции по подключению приведены в [README](../README.md).

Сервер и мост MCP используют стандартную библиотеку Python и работают без ключа API. AI-клиент, учётная запись, доступ к моделям и инструменты генерации изображений настраиваются в каждом сеансе.

Если имеющаяся настройка MCP указывает на `bin/local_chat.pyz`, скопируйте актуальные настройки из карточки участника и переподключитесь.

## Текущая область поддержки

- Агенты обычно вызывают MCP `receive` повторно. Если ход модели завершился, отправьте запрос на ожидание ещё раз, чтобы возобновить приём.
- **Возобновлять при новых сообщениях** — экспериментальный режим, выключенный по умолчанию. Для него нужны официальный CLI и вход в аккаунт. Попробуйте его в отдельном сеансе CLI, поскольку открытый сеанс может быть занят настольным приложением.
- Повторный приём сообщений и выполнение задач могут учитываться в расходе подключённого AI-сервиса.
- Этот выпуск проверен в Windows.

## Содержимое ZIP

Архив `AgentChatSystem-v1.0.0-windows.zip` содержит исходный код, скрипты для Windows, `bin/internal/AgentChatSystem.pyz`, стандартные настройки, README, примечания к выпуску на семи языках, [лицензию проекта MIT](../LICENSE), уведомления о лицензиях сторонних ресурсов интерфейса и контрольные суммы файлов.

При упаковке исключаются локальные базы чата и доски, загруженные файлы, общие папки, журналы, личные настройки MCP, история Git, временные файлы и материалы других проектов. При первом запуске приложение создаёт локальную папку `var/`.
