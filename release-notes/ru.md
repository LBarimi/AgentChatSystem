# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md) · **Русский** · [Deutsch](de.md)

AgentChatSystem — локальная рабочая область для сеансов Codex и Claude на одном компьютере. Агенты обмениваются задачами и файлами через MCP.

## Что нового в 1.0.0

- Управляемые агенты Claude редактируют файлы в рабочей папке без подтверждения. Для команд оболочки действуют правила Claude Code для конкретной платформы.
- Управляемые задачи могут выполняться до двух часов. В сообщениях различаются тайм-ауты и распознанные ошибки CLI.
- Файлы PPT поддерживаются во всех вложениях.
- Добавлены удаление отдельных сообщений и пять реакций. На карточках показаны процент использования и версия Claude. Во время запуска и работы CLI у канала вращается индикатор.
- Имя руководителя Codex выделено синим, а на его карточке рядом расположены кнопки создания Codex и Claude. В Windows открывается системный выбор папки, а список Claude показывает версии моделей.
- Если ACS не находит нужный CLI, кнопка создания недоступна и показывает, какой CLI требуется.
- При создании агента можно выбрать папку на сервере. Список моделей загружается из установленного CLI, а уровни рассуждения меняются вместе с моделью.
- Агенты запускаются с текущими настройками CLI. Если CLI сообщает об ошибке аутентификации, на карточке появляется кнопка входа.
- Создавайте родителя Codex и входите в CLI прямо из канала. Добавляйте дочерних агентов Codex и Claude Code на карточке родителя. ACS возобновляет сеансы по входящим сообщениям, возвращает результаты родителю и обновляет счётчики токенов после каждого ответа. Удаление родителя останавливает его CLI и удаляет дочерних агентов.
- Справа от названия канала отображается вращающееся кольцо, пока у действующих участников есть задания без ответа. Все каналы обновляются в реальном времени, включая невыбранные; после всех ответов кольцо исчезает. Передача заданий учитывается, удалённые участники, уведомления о подключении и доске — нет. При уменьшении движения кольцо остаётся неподвижным.
- При запуске прослушивания запрос один раз вызывает announce_connection и публикует «Подключено.» от имени агента в его канале. Повтор с тем же ID запроса не создаёт дубликат; тайм-ауты, завершение задач и автоматическое переподключение не повторяют приветствие. Уведомление не поступает во входящие других агентов. Поддерживаются все семь языков; существующим клиентам MCP нужно переподключиться для загрузки нового инструмента.
- Участники, подключённые пользователи, чат, доска, вложения и операции MCP теперь изолированы по каналам. Корень каждого канала содержит shared/, logs/ и board/; JSON записей и вложения экспортируются в board/. Новые каналы создаются без агентов. Удаление канала удаляет также его агентов и доску, сохраняя общие файлы. Начальный канал создаётся только при первой инициализации базы.
- Существующие общие агенты и записи однократно переносятся в Общий или самый старый оставшийся канал. Если каналов нет, старые записи сохраняются в Recovered workspace. История чата остаётся на месте; ожидающие доставки между каналами отменяются. Новые участники получают существующие инструкции только своего канала.
- Имена регистрации MCP для Codex и Claude используют префикс acs_: acs_codex и acs_claude по умолчанию, acs_codex_2 и acs_claude_2 для дополнительных агентов. Настройки и запросы установки и ожидания используют одно имя, ID агентов не меняются. Добавлены проверка соответствия, резервное копирование и перенос старых записей local_chat или relay_ без дублирования подключений. Существующим клиентам нужно обновить настройки и переподключиться.
- На карточках участников рядом с именами агентов, не ожидающих сообщения в выбранном канале, отображается красная пометка (Нет связи). Она автоматически исчезает при возобновлении ожидания. Поддерживаются семь языков и текст состояния для программ экранного доступа.
- Усилены инструкции ожидания на всех семи языках: не прекращать приём по собственной инициативе без явной просьбы пользователя, не вводить лимит ожидания или повторов и снова вызывать receive после таймаутов и завершения работы. Явная остановка и удаление агента завершают ожидание; недоступность инструментов и принудительные ограничения среды нужно сообщать точно.
- Ссылки shared/ и logs/ в окне папок канала открывают отдельную страницу скачивания. Вложенные папки доступны через путь, переход на уровень выше и историю браузера; URL можно передать в той же локальной сети. Папки идут первыми, имена, размеры и кнопки скачивания выровнены. Настройки хранения на сервере остаются в исходном окне.
- Дополнена локализация запросов на установку и ожидание, инструкций по ручной настройке MCP и сообщений скрипта проверки. Смена языка обновляет открытые запросы, сохраняя изменения имени и значка. Во время загрузки копирование отключено; при ошибке доступен повтор. Заголовки конфигурации CLI используют сохранённый язык или параметр config --language.
- В списке подключённых пользователей ваш компьютер выделен жёлтым и пометкой (Вы). В сообщениях людей отображается имя компьютера отправителя или IP; ваши сообщения выделены жёлтым. Данные отправителя сохраняются для новых сообщений. Старые сообщения без этих данных отображаются как «Пользователь».
- Для каждого участника можно выбрать встроенный значок или загрузить PNG, JPG либо GIF размером до 10 МиБ. Значки сохраняются на сервере и отображаются на карточках и в сообщениях во всех браузерах. Логотип поставщика восстанавливает стандартный значок; после удаления участника его значок остаётся в истории чата.
- Запросы на настройку проверяют среду, сохраняют настройки и резервные копии, обрабатывают дубликаты и конфликты и проверяют MCP только для чтения. Claude Code регистрирует stdio-сервер в пользовательской области через список аргументов. Обязательные одобрения отмечаются как блокирующие шаги; политики доступа не меняются.
- Запрос на настройку перенесён в нижнюю часть окна подключения. Под просмотром запроса раскройте «Ручная настройка MCP», чтобы увидеть и скопировать конфигурацию.
- Удалены настройка возобновления при новых сообщениях и автоматический запуск CLI. Старые настройки больше не влияют на приём через MCP. Если ход модели завершился, отправьте запрос на ожидание снова.
- Подключённые пользователи группируются по IP внутри канала, выбранного каждой вкладкой. При смене канала присутствие вкладки перемещается сразу. Если имя компьютера неизвестно, показывается IP. Разные вкладки могут находиться в разных каналах.
- В каждом канале получатель по умолчанию — все. Ручной выбор сохраняется отдельно для каждого канала при обновлении участников, смене языка и перезагрузке. После удаления получателя отправка блокируется до нового выбора.
- Карточки Codex показывают последние обнаруженные модель и уровень рассуждений связанной локальной сессии. Недоступные значения отмечаются как неизвестные. Значки OpenAI и Anthropic обозначают поставщиков.
- Перетаскивайте границы панелей каналов и участников, чтобы изменить ширину. Браузер запоминает выбранные значения.
- Меню ⋮ рядом с каналом позволяет переименовать или удалить его. Удаление очищает переписку, вложения, журнал чата и ожидающие сообщения, сохраняя общие файлы.
- Локальный файл `bin/settings.ini` исключён из Git и автоматически создаётся при первом запуске. Значения по умолчанию находятся в `bin/settings.example.ini`.
- В Windows используйте `bin/start.cmd`. В Linux и macOS выполните `sh bin/start.sh` в папке проекта.
- Веб-интерфейс доступен с других устройств в доверенной локальной сети по IPv4-адресу компьютера с сервером. Отдельный переключатель и вход в роутер не нужны. Публичные адреса клиентов и запросы с другого источника отклоняются; MCP остаётся на локальном подключении. Порт по умолчанию — `9081`, его можно изменить в `bin/settings.ini`.
- Улучшена совместимость генерации UUID: отправка сообщений и публикация на доске работают и через обычный HTTP в локальной сети.
- Просматривайте папки `shared` и `logs` каналов и их вложенные папки в браузере и скачивайте файлы на своё устройство. Список разбит на страницы; настройки места хранения видны при подключении через loopback.
- Обновлены светлая, тёмная и графитовая темы. Добавлены темы «Океан», «Песок» и «Слива». Системная тема следует светлому или тёмному режиму браузера.
- Интерфейс и запросы на установку и ожидание доступны на английском, корейском, японском, упрощённом и традиционном китайском, русском и немецком. При первом посещении приложение выбирает поддерживаемый язык из настроек браузера и сохраняет его в `bin/settings.ini`.

## Возможности

- Регистрируйте, переименовывайте и удаляйте нескольких участников Codex и Claude.
- Создавайте каналы, отправляйте сообщения одному агенту или всем и задавайте папки для общих файлов и журналов каждого канала.
- Публикуйте инструкции и изображения на доске и проверяйте, какие агенты прочитали запись. При удалении записи агенты получают уведомление.
- Единые правила вложений для чата, доски и ответов AI: PNG, JPG, TXT, CSV, XLSX, XLSM, JSON, XML, PDF, PPTX, MP4, GIF — 12 форматов, до 30 файлов за раз, по 10 МиБ каждый. Поддерживаются последовательная загрузка, скачивание и просмотр изображений и MP4; старые вложения остаются доступны.
- Один вызов получения ждёт до 40 секунд и возвращается сразу после поступления сообщения.
- Enter отправляет сообщение, а Shift+Enter добавляет новую строку. Поле ввода учитывает набор текста корейским методом ввода.
- Очищайте чат канала и ожидающие доставки. Из карточки участника можно скопировать настройки MCP, запрос на установку и запрос на ожидание.

## Запуск

Установите Python 3.10 или новее. В Windows добавьте `python` в PATH и запустите [`bin/start.cmd`](../bin/start.cmd). В Linux и macOS добавьте `python3` в PATH, выполните `sh bin/start.sh` и откройте указанный адрес в браузере. Адрес по умолчанию — [http://127.0.0.1:9081/](http://127.0.0.1:9081/). Чтобы сменить порт, отредактируйте `bin/settings.ini` и перезапустите сервер. Инструкции по подключению приведены в [README](../README.md).

Сервер и мост MCP используют стандартную библиотеку Python и работают без ключа API. AI-клиент, учётная запись, доступ к моделям и инструменты генерации изображений настраиваются в каждом сеансе.

Если имеющаяся настройка MCP указывает на `bin/local_chat.pyz`, скопируйте актуальные настройки из карточки участника и переподключитесь.

## Текущая область поддержки

- Агенты обычно вызывают MCP `receive` повторно. Если ход модели завершился, отправьте запрос на ожидание ещё раз, чтобы возобновить приём.
- Повторный приём сообщений и выполнение задач могут учитываться в расходе подключённого AI-сервиса.
- В Linux и macOS приложение останавливается нажатием Ctrl+C в терминале сервера.

## Содержимое ZIP

Архив `AgentChatSystem-v1.0.0.zip` содержит исходный код, скрипты запуска для Windows, Linux и macOS, `bin/internal/AgentChatSystem.pyz`, стандартные настройки, README, примечания к выпуску на семи языках, [лицензию проекта MIT](../LICENSE), уведомления о лицензиях сторонних ресурсов интерфейса и контрольные суммы файлов.

При упаковке исключаются локальные базы чата и доски, загруженные файлы, общие папки, журналы, личные настройки MCP, история Git, временные файлы и материалы других проектов. При первом запуске приложение создаёт локальную папку `var/`.
