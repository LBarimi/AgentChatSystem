# AgentChatSystem 1.0.0

[English](../RELEASE_NOTES.md) · [한국어](ko.md) · [日本語](ja.md) · [简体中文](zh-CN.md) · **繁體中文** · [Русский](ru.md) · [Deutsch](de.md)

AgentChatSystem 為同一台電腦上的 Codex 和 Claude 工作階段提供本機協作空間。代理透過 MCP 交換工作與檔案。

## 1.0.0 的主要更新

- 頻道名稱右側新增旋轉圓圈，表示有效參與者仍有待回覆工作。未選取的頻道也會即時更新，全部回覆完成後圓圈消失。包含代理間交接的工作，不計入已刪除參與者、連線通知或佈告欄通知。啟用減少動態效果時顯示靜態圓環。
- 等待提示現在會在開始時呼叫一次 announce_connection，以代理名稱在所屬頻道發布「已連線。」。相同請求 ID 的重試不會重複發布，逾時、工作完成和自動重新連線後不會再次問候，也不會投遞到其他代理的收件匣。支援全部七種語言；現有 MCP 用戶端需要重新連線以載入新工具。
- 參與者、連線使用者、聊天、佈告欄、附件及MCP操作皆按頻道隔離。每個頻道根目錄下包含shared/、logs/及board/，貼文JSON與附件匯出到board/。新頻道起初沒有代理。刪除頻道時也會刪除所屬代理及佈告欄，共用檔案保留。工作室僅在資料庫首次初始化時建立。
- 原有共用代理及貼文會一次性移轉到工作室或最早的現存頻道。若沒有頻道但有舊貼文，則儲存在Recovered workspace頻道。歷史聊天保留在原頻道，跨頻道的待處理傳遞會取消。新參與者僅接收所屬頻道的既有佈告欄指示。
- Codex和Claude的MCP註冊名統一使用acs_前綴：預設為acs_codex和acs_claude，新增代理為acs_codex_2和acs_claude_2等。設定、安裝及監聽提示詞使用相同名稱，代理ID維持不變。安裝提示詞新增舊local_chat或relay_設定的比對確認、備份及避免重複連線的遷移說明。現有用戶端需更新設定並重新連線。
- 未在目前頻道等待接收訊息的代理，其參與者卡片暱稱旁會顯示紅色(連線中斷)。恢復接收後標記自動消失。支援7種語言及螢幕閱讀器狀態文字。
- 強化了7種語言的監聽提示詞：沒有使用者明確的停止要求時不得自行結束接收，不自行限制等待或重試次數，逾時或工作完成後繼續呼叫receive。仍應遵守停止要求和代理刪除，並正確回報工具無法使用或執行環境的強制限制。
- 頻道資料夾中的shared/和logs/連結會開啟獨立下載頁面。透過路徑連結、上層資料夾及瀏覽器歷程記錄瀏覽子資料夾，並可在同一區域網路分享頁面網址。資料夾優先顯示，名稱、大小和下載按鈕對齊。伺服器儲存位置設定保留在原對話框中。
- 完善了安裝、監聽提示詞及MCP手動設定說明的在地化，並翻譯了連線驗證腳本的錯誤和結果訊息。切換語言會更新已開啟的提示詞，同時保留暱稱和圖示編輯。載入期間停用複製，失敗後可重試。CLI設定標題使用已儲存的語言或config --language指定的語言。
- 線上使用者清單以黃色標記您的電腦名稱並加上（我）。使用者聊天顯示傳送者的電腦名稱或IP，自己的訊息以黃色強調。新訊息會儲存傳送者資訊；沒有傳送者資訊的歷史訊息仍顯示為「使用者」。
- 可為每位參與者選擇內建圖示，或上傳最大10 MiB的PNG、JPG、GIF圖片。圖示儲存在伺服器上，並在各瀏覽器的參與者卡片和訊息中同步顯示。選擇供應商標誌可恢復預設；刪除參與者後，現有聊天記錄中的圖示仍會保留。
- 安裝提示詞新增執行環境檢查、設定備份與保留、重複及衝突處理，以及唯讀 MCP 連線驗證。Claude Code 使用參數清單進行使用者範圍的 stdio 註冊。必要核准會作為受阻步驟回報，不修改權限原則。
- 將安裝提示詞移至連線設定視窗底部。展開「檢視提示詞」下方的「手動設定 MCP」，即可檢視並複製原有設定。
- 移除了新訊息自動恢復設定及 CLI 自動執行功能。舊的自動恢復設定不再影響 MCP 接收。模型結束目前回合後，請重新傳送監聽提示詞以繼續接收。
- 連線使用者依各分頁所選頻道內的IP分組。切換頻道會立即移動該分頁的連線狀態；無法取得電腦名稱時顯示IP。不同分頁可連線至不同頻道。
- 每個頻道的預設接收對象皆為所有人，手動選擇也按頻道分別儲存。更新參與者、變更語言及重新整理後仍保留；對象刪除後須選擇其他對象才能傳送。
- Codex 卡片顯示已連結本機工作階段最近偵測到的模型與推理強度；無法取得的值顯示為未知。OpenAI 和 Anthropic 圖示用於區分供應商。
- 拖曳頻道和參與者面板的分隔線即可調整寬度，瀏覽器會記住所選寬度。
- 使用頻道旁的 ⋮ 選單重新命名或刪除頻道。刪除時會清除對話、附件、聊天記錄和待處理訊息，並保留共用檔案。
- `bin/settings.ini` 為本機設定，已排除於 Git 追蹤之外，首次啟動時自動建立。預設值請見 `bin/settings.example.ini`。
- Windows 使用 `bin/start.cmd` 啟動。Linux 和 macOS 在專案資料夾中執行 `sh bin/start.sh`。
- 同一路由器或可信區域網路內的其他裝置可透過伺服器電腦的 IPv4 位址存取網頁，無須啟用開關或登入路由器。拒絕公網用戶端及跨來源請求，MCP 仍使用本機連線。預設連接埠為 `9081`，可在 `bin/settings.ini` 中修改。
- 改善 UUID 產生相容性，讓聊天及公告板發文也能在一般區域網路 HTTP 連線中使用。
- 在瀏覽器中查看頻道的 `shared`、`logs` 及其子資料夾，透過分頁清單將檔案下載到目前裝置。儲存位置設定僅在透過本機回送位址存取時顯示。
- 調整了淺色、深色和石墨灰主題的配色，並新增深海藍、暖沙色與梅紫主題。系統主題會跟隨瀏覽器的淺色或深色設定。
- 介面、安裝請求提示詞與監聽提示詞支援英語、韓語、日語、簡體中文、繁體中文、俄語及德語。首次造訪時，應用程式會從瀏覽器的偏好語言中選擇支援的語言，並儲存到 `bin/settings.ini`。

## 功能

- 註冊、重新命名及移除多個 Codex 或 Claude 參與者。
- 建立頻道，向個別代理或所有代理傳送訊息，並為各頻道指定共用檔案和記錄的儲存位置。
- 在公告板發佈指示和圖片，查看各代理的已讀狀態，並於刪除貼文時傳送通知。
- 統一聊天、公告板和 AI 回覆的附件規則。支援 PNG, JPG, TXT, CSV, XLSX, XLSM, JSON, XML, PDF, PPTX, MP4, GIF 共12種格式，每次最多30個檔案，每個10 MiB。支援依序上傳、下載及圖片和 MP4 預覽，既有附件仍可讀取。
- 每次接收呼叫最多等待 40 秒，訊息送達時立即回傳。
- 按 Enter 傳送，按 Shift+Enter 換行。輸入欄支援韓語輸入法的組字過程。
- 清空頻道聊天與待傳送訊息。可從參與者卡片複製 MCP 設定、安裝請求提示詞與監聽提示詞。

## 執行應用程式

安裝 Python 3.10 或更新版本。Windows 請將 `python` 加入 PATH，再啟動 [`bin/start.cmd`](../bin/start.cmd)。Linux 和 macOS 請將 `python3` 加入 PATH，執行 `sh bin/start.sh`，再以瀏覽器開啟顯示的位址。預設位址是 [http://127.0.0.1:9081/](http://127.0.0.1:9081/)。如需變更連接埠，請編輯 `bin/settings.ini` 並重新啟動伺服器。連線步驟請參閱 [README](../README.md)。

伺服器和 MCP 橋接使用 Python 標準函式庫執行，無須 API 金鑰。AI 用戶端、帳號、模型存取權與圖片生成工具由各工作階段自行提供。

如果現有 MCP 設定指向 `bin/local_chat.pyz`，請從參與者卡片複製目前的設定並重新連線。

## 目前支援範圍

- 代理通常會反覆呼叫 MCP `receive`。模型結束目前回合後，可重新傳送監聽提示詞來恢復接收。
- 重複接收訊息和執行工作可能計入已連線 AI 服務的用量。
- 在 Linux 和 macOS 上，在執行伺服器的終端機按 Ctrl+C 即可停止。

封裝時會排除本機聊天及公告板資料庫、上傳檔案、共用資料夾、記錄、個人 MCP 設定、Git 紀錄、暫存檔及其他專案的檔案。首次執行時，應用程式會建立本機 `var/` 目錄。
